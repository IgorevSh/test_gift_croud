# Социальный вишлист

Веб-приложение: пользователь создаёт списки желаний, добавляет товары (название, ссылка, цена, картинка), делится списком по ссылке. Друзья могут резервировать подарки и скидываться на дорогие. Владелец не видит, кто что зарезервировал или внёс. Обновления в реальном времени (WebSocket).

## Стек

- **Frontend:** React, Redux Toolkit, React Router, SCSS, Socket.IO Client
- **Backend:** Nest.js, PostgreSQL, Sequelize, JWT, Socket.IO
- **Стиль:** Flat Design, переключение светлой/тёмной темы

## Запуск

### 1. PostgreSQL

Создайте базу и пользователя (или используйте существующие). Пример:

```bash
createdb wishlist_db
```

### 2. Backend

```bash
cd backend
cp .env.example .env
# Отредактируйте .env (DB_*, JWT_SECRET)
npm install
npm run start:dev
```

API: http://localhost:3001

### 3. Frontend

```bash
cd frontend
cp .env.example .env   # по желанию: задать VITE_API_URL для продакшена
npm install
npm run dev
```

Сайт: http://localhost:3000

При разработке прокси Vite отправляет запросы на бэкенд — **VITE_API_URL** можно не задавать. В продакшене укажи в `.env` полный URL API (например `https://api.example.com`) — тогда и axios, и Socket.IO будут обращаться к нему.

## Основные сценарии

- **Регистрация/вход:** email + пароль.
- **Мои вишлисты:** создание списков, добавление пунктов (название, ссылка, цена, картинка, при необходимости — целевая сумма сбора и мин. взнос).
- **Поделиться:** копирование ссылки вида `/w/<token>`. Просмотр по ссылке без регистрации; для гостя показывается полупрозрачный оверлей с предложением войти.
- **Пустой список:** отображается скелет с пустыми карточками.
- **Резерв:** гость/друг нажимает «Зарезервировать» — владелец видит только факт «зарезервировано», без имени.
- **Сбор:** если у пункта задана целевая сумма, друзья могут вносить вклад; прогресс-бар и сумма собраного видны всем, кто внёс — только владельцу не показывается.
- **Реалтайм:** при резерве или взносе все открытые страницы этого вишлиста обновляются без перезагрузки (Socket.IO).

## Переключение темы

В шапке (для авторизованных) — кнопка переключения светлой/тёмной темы. Выбор сохраняется в `localStorage`.
